---
name: Research then implement
description: Gather facts first, then build from verified information.
when_to_use: A task needs outside facts or API details before code or a document can be right.
tags: research,code,collaboration,coordination
---
1. ask_agent researcher for the exact facts needed, with sources.
2. Write the key facts on the blackboard.
3. Have the coder or writer work from the blackboard, not from memory.
4. Mention any fact the researcher could not verify.
