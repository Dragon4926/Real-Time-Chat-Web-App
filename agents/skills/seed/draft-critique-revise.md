---
name: Draft, critique, revise
description: Improve important text or code with one review round.
when_to_use: The output matters and quality is uncertain: reports, emails, non-trivial code.
tags: writing,review,quality,collaboration
---
1. Produce a first draft (writer or coder).
2. ask_agent critic with the full draft and the goal.
3. Apply only the concrete fixes; do not loop more than once.
4. Return the revised result with a one-line note of what changed.
